# GreenIQ – Smart Greenhouse Management System 

**GreenIQ** is an intelligent greenhouse management system developed to help farmers monitor and manage greenhouse conditions using IoT technology, automation, and Artificial Intelligence.

The project aims to improve agricultural productivity by providing real-time environmental monitoring, automated control, and intelligent recommendations.

## Main Features

- **Real-Time Monitoring:** Monitor temperature, air humidity, soil moisture, and light intensity.
- **Smart Automation:** Automatically control greenhouse equipment based on environmental conditions.
- **Manual Control:** Allow users to manually operate devices such as water pumps, fans, and lights.
- **AI Assistant:** Provide intelligent agricultural recommendations and analyze greenhouse conditions.
- **Plant Configuration:** Define suitable environmental thresholds according to different plant types.
- **Notifications:** Receive alerts when environmental parameters exceed their configured limits.
- **Multilingual Interface:** Support for English, French, and Arabic.

## Technologies Used

- **Mobile Application:** Flutter & Dart
- **IoT Hardware:** ESP32 and environmental sensors
- **Database:** Firebase Realtime Database
- **Artificial Intelligence:** AI-powered analysis and recommendations
- **Backend:** Node.js & Express

## Project Architecture

GreenIQ connects an IoT-based greenhouse monitoring system to a Flutter mobile application through Firebase and backend services.

The system collects environmental data, displays real-time information, and enables automatic or manual control of greenhouse devices.

## Project Objective

To develop an accessible and intelligent agricultural solution that helps farmers optimize greenhouse conditions, reduce unnecessary resource consumption, and make better farming decisions.
